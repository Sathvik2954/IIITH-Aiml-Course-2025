## Curriculum Overview

The program covered the following topics across 5 months:

1. Introduction to ML — Data, Model, Evaluation
2. Nearest Neighbor Classification
3. Retrieval, Performance Evaluation, and Metrics
4. Linear Classifiers
5. Representing Textual Data
6. Perceptrons and Gradient Descent
7. Loss Functions
8. Regression
9. Clustering
10. Feature Selection and PCA
11. Multi-Layer Perceptron
12. Probabilistic ML Models
13. Deep Learning Architectures
